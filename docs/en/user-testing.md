# User-testing script with 3–5 freelancers or small businesses (20 min each)

[Español](../../PRUEBA_CON_USUARIOS.md) · **English**

Setup: `Iniciar REM Negocio.command`, empty data. Do not explain anything; watch and note where they hesitate.

| # | Task | Success if… | Notes |
|---|---|---|---|
| 1 | Fill in their business details | Done unaided in < 2 min | |
| 2 | Import their clients from Excel/CSV | All of them appear | columns not recognised |
| 3 | Create and issue an invoice | < 3 min, understands it can no longer be edited | |
| 4 | Record a partial payment | | |
| 5 | Chase an overdue invoice | Understands they must send the message themselves | |
| 6 | Make a quote and convert it into an invoice | | |
| 7 | Find «how much VAT do I owe this quarter» | | |
| 8 | Type in the Today bar «factura a (a client) por 3 horas a 40 €» | Understands they must confirm and that a draft is created | |
| 9 | Share the client link and get someone to write | Receives the message and sends a quote | whether they hesitate when requesting payment |

Final questions: would you use it instead of what you use today? What is missing for you to drop your current tool? How much would you pay (one-off / monthly)? Does it worry you that it is not VeriFactu-certified?

Decide price and scope with these answers, not before.
