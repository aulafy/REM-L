Skill para Claude Code

Hazla tuya, sin romper nada

Abres el proyecto con tu asistente de IA y le pides una ampliación para tu negocio:

«Quiero guardar la matrícula y la
próxima ITV de cada cliente»

{ "id": "taller-itv",
  "custom_fields": [
    { "key": "matricula",   "type": "text" },
    { "key": "proxima_itv", "type": "date" } ] }

✔ Módulo válido · 2 campos en clientes
  No usa internet, no envía mensajes
  y no borra datos

Las ampliaciones son datos validados, no código: lo peor que puede pasar es un campo mal configurado.
