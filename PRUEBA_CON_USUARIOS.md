# Guion de prueba con 3–5 autónomos o pymes (20 min cada uno)

Preparación: `Iniciar REM Negocio.command`, datos vacíos. No expliques nada; observa y anota dónde dudan.

| # | Tarea | Éxito si… | Anota |
|---|---|---|---|
| 1 | Rellenar los datos de su negocio | Lo logra sin ayuda en < 2 min | |
| 2 | Importar sus clientes desde un Excel/CSV | Aparecen todos | columnas que no reconoce |
| 3 | Crear y emitir una factura | < 3 min, entiende que ya no se edita | |
| 4 | Registrar un cobro parcial | | |
| 5 | Reclamar una factura vencida | Entiende que debe enviar él el mensaje | |
| 6 | Hacer un presupuesto y convertirlo en factura | | |
| 7 | Encontrar «cuánto IVA debo este trimestre» | | |
| 8 | Escribir en la barra de Hoy «factura a (un cliente) por 3 horas a 40 €» | Entiende que debe confirmar y que sale un borrador | |
| 9 | Compartir el enlace de cliente y que alguien le escriba | Recibe el mensaje y envía un presupuesto | si duda al pedir el pago |

Preguntas finales: ¿lo usarías en lugar de lo que usas hoy? ¿qué te falta para dejar tu herramienta actual? ¿cuánto pagarías (pago único / mensual)? ¿te preocupa que no sea Verifactu?

Decide precio y alcance con estas respuestas, no antes.
